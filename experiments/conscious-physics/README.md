# Historical Conscious Physics Demonstrations

**Status: exploratory prototypes using synthetic/random data. Not validated physical simulations.**

`PH_1.ipynb`, `PH_2.ipynb`, and `PH_3.ipynb` preserve the source progression. Their source cells include:

- Randomly generated masses and lags in placeholder `Simulator` methods.
- Fits and uncertainty estimates applied to those generated values.
- Repeated `%%writefile` replacements of local Python modules, including incomplete intermediate versions.
- Browser-environment dependency installation with `micropip`.

All former code cells are now displayed as fenced text inside markdown cells. Saved outputs and notebook metadata were cleared. Opening or running all cells in these public copies will not install packages or overwrite modules. The transformations are recorded in the source map.

The saved figures and one readable animation are retained for historical context. A damaged alternative animation was excluded from edition `2026.10.07.1`; its original remains in the author's private source archive. Every frame of the retained animation was decoded during packaging. These visualizations do not supply the missing physical model or prove the stated interpretation, and the collapse-wave animation is not a documented output of the BIH-VI A2 instrument.
