# Please Cite This Work

Please cite Lou Thomas and the repository revision when using its code, manuscripts, figures, or results. For research focused on one project, name that project and the relevant document as well.

Suggested citation before a repository URL or DOI has been assigned:

> Thomas, Lou. *Lou Thomas Physics Research: BIH-VI, RNSF, and Foundations*. Collection edition 2026.10.07. AI-assisted personal research software and manuscripts.

After publication, add the actual repository URL and the commit or release identifier to the citation. A repository URL, DOI, release date, or scholarly publication has not been invented in this local preparation.

GitHub recognizes the root `CITATION.cff` and provides a "Cite this repository" action. A future archived release may be assigned a DOI by an external archival service; creating one is a separate publication action.

Citation is requested for scholarly use. Legal attribution obligations depend on the applicable license. MIT requires retention of the copyright and permission notice in copies or substantial portions of the software; it does not impose a universal academic-citation requirement. CC BY 4.0 requires attribution for licensed reuse subject to its terms and exceptions. Neither license makes ownership claims over scientific facts or independently developed ideas.
