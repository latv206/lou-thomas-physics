# Version Selection And Historical Context

Edition: `2026.10.07.1`. This is a consolidated distribution, not a new version of every underlying scientific theory.

This privacy-maintenance revision standardizes public author credit, removes personal affiliation locations and unfilled contact templates, and excludes one damaged alternative animation. The scientific code, numerical records, and manuscript bodies are unchanged. The source map and release checksums describe the revised public files.

## Selection Method

The supplied Theories directory was inventoried by path and SHA-256, including ZIP contents. BIH files were compared with the corresponding July 2026 packages in recovered Hub backup directories. Duplicates were identified by content hash, not filename or modification time alone. Copy dates do not establish scientific revision order.

"Latest" here means the latest identifiable revision within that inspected collection and the matching recovered packages. It is not a claim that every drive, chat, or inaccessible workspace was searched.

## A2 Provenance Distinction

The Theories closeout ZIP has SHA-256 `083d8d0b533283c3c5527602ddbd1073d1336c29bab27252305fea813659fce3`; it predates the additional firewall files. The corrected historical ZIP hash was recorded as `844a376c6494d8cd70dbad34bc293d4d8a817bc30558571c18b4b730af9be7e6`. This edition recovers and checks the corrected directory's files. It does **not** claim to reproduce that historical ZIP byte for byte.

Source checksum lists verified before export: 19 entries in the data-lock package, 25 in the hardened manuscript package, 8 in the corrected closeout, and 5 in the corrected evidence bundle, 57 total. Historical checksum records describe historical bytes; they are not reused to certify sanitized copies.

The original foundation audit includes claims about files that were then external to its Hub. A few early artifacts, including a `final_A2_closure: false` record, are now present among recovered ZIP-only history. Their recovery confirms those particular artifacts, not the broader assertion that a derivation exists nowhere. The global absence claim remains unsupported by this distribution alone.

## Transformations

The [source map](SOURCE_MAP.csv) gives a source-relative identifier, original hash, public destination, public hash, and transformation for each selected source reference. Original references use logical roots (`theories/`, `hub-backup/`), not personal filesystem addresses.

Byte-identical duplicates map to one public file. Distinct earlier versions remain under `archive/`. Private material and unrelated operational packaging are not carried forward. A mislabeled `.pdf` containing TeX was recovered with a `.tex` extension. Legacy code extensions and notebook execution cells were changed as described in the code review.

Six image references in the historical GMT-SSC HTML report could not be resolved within the supplied sources. The public copy names those missing figures explicitly instead of showing broken images or fabricating replacements.

Readers should begin with the new overview and project READMEs. Historical filenames containing `FINAL`, `READY`, `PASSED`, or `CLOSED` are historical labels; they do not override the current evidence and claims boundaries.
