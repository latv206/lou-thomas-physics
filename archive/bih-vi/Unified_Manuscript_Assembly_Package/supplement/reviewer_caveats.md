# Reviewer-facing caveats

Use these points proactively in the manuscript.

1. BIH-VI is an EFT-level cosmological framework, not a UV-complete microscopic substrate theory.
2. The Sqrt-Reg/EFT-clock early branch is frozen; late-universe parameters do not retune inflation.
3. The metric-lapse branch failed diagnostic distance-gate tests and is not the proposed late-time mechanism.
4. The calibration-frame offset Delta M_B ~ 0.18 mag is the current target implied by the local/global H0 ratio, not yet a first-principles prediction.
5. CPL is a reconstruction scaffold, not the final substrate-stress law.
6. Q_bulk is a falsifier. Smooth and bounded Q_bulk supports the C3 architecture; kinks, oscillations, or sign-flip chatter undermine it.
7. Production posterior claims require full Pantheon+ covariance, DESI DR2 BAO likelihood, CMB acoustic priors, and independent-anchor tests.
