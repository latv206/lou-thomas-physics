BIH-VI Technical Report Package

Contents:
- BIH-VI_Technical_Report_FINAL.docx: editable Word report.
- BIH-VI_Technical_Report_FINAL.pdf: rendered PDF version.
- bih_vi_ns_r_scan_clean.png: (n_s, r) parameter scan.
- bih_vi_ns_heatmap_clean.png: spectral tilt heatmap over (mu, p).
- bih_vi_r_heatmap_clean.png: tensor ratio heatmap over (mu, p).
- bih_vi_parameter_scan_clean.csv: full parameter scan data.
- bih_vi_benchmark_table.csv: benchmark p=3 line.
- bih_vi_scan_summary.csv: viable-region summary.
- bih_vi_exit_feature_dlnP.png: slow-roll exit-feature estimate.
- bih_vi_exit_switch_stress_test.csv: switch-width stress-test table.
- bih_vi_ms_convergence_delta001.png: Mukhanov-Sasaki convergence plot for Delta=0.01.
- bih_vi_ms_convergence_nonadiabaticity.png: switch non-adiabaticity plot.
- bih_vi_ms_convergence_summary.csv: M-S convergence summary.
- bih_vi_ms_convergence_diffs.csv: M-S convergence differences.

Scope:
This package freezes BIH-VI as an EFT-level realization of a Sqrt-Reg entropy-selected cosmological background. It does not claim a unique UV-complete microscopic theory.
