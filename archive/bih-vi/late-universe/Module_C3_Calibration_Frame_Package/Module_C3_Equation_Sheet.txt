3. Geometry sector

    E_BIH^2(z) =
        Omega_r(1+z)^4
      + Omega_m(1+z)^3
      + Omega_DE,0 f_DE(z)

CPL diagnostic:
    w_eff(z) = w0 + wa z/(1+z)

    f_DE(z) =
        (1+z)^{3(1+w0+wa)}
        exp[-3 wa z/(1+z)]

Distances:
    D_C(z) = c int_0^z dz'/[H0_geom E_BIH(z')]
    D_M = D_C for flat diagnostic
    D_H = c/[H0_geom E_BIH(z)]
    D_L = (1+z)D_M

4. Bulk exchange reconstruction

    dot rho_DE + 3H(1+w_int)rho_DE = Q_bulk

Effective equation:
    dot rho_DE + 3H(1+w_eff)rho_DE = 0

Therefore:
    Q_bulk/(H rho_DE) = 3(w_int - w_eff)

For w_int = -1:
    Q_bulk/(H rho_DE) = -3[1+w_eff(z)]

Interpretation:
    w_eff < -1  => Q_bulk > 0, energy enters DE-like sector.
    w_eff > -1  => Q_bulk < 0, energy drains from DE-like sector.
